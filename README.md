# PrescriptX

Offline prescription management desktop app for a single doctor. Built with Tauri v2, React, and TypeScript, with a Rust backend and SQLite storage.

## Project Setup

### Prerequisites

- [Bun](https://bun.sh)
- [Rust toolchain](https://www.rust-lang.org/tools/install) (required by Tauri)
- Platform-specific Tauri prerequisites: https://v2.tauri.app/start/prerequisites/

### Install

```bash
$ bun install
```

### Development

```bash
$ bun run dev
```

### Build

```bash
# Builds a bundle for the current operating system
$ bun run build
```
